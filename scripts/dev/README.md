# 本地前后端一键脚本

```bash
./scripts/dev/dev-services.sh start       # 启动
./scripts/dev/dev-services.sh restart     # 重启
./scripts/dev/dev-services.sh stop        # 停止
./scripts/dev/dev-services.sh status      # 状态
./scripts/dev/dev-services.sh start-open  # 启动并打开浏览器
```

Cloud / VNC 桌面另有快捷方式（`~/Desktop/`），调用本脚本。

打开页面：
- 前端 http://127.0.0.1:5173/login
- 后端健康 http://127.0.0.1:8000/health
